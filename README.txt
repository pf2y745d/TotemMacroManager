TotemMacroManager
-----------------

Installation:
1. Copy the TotemMacroManager folder to your AddOns directory.
2. In-game, enable the addon on the character select screen.

Usage:
- Type /tmm to show or hide the movable TMM widget.
- Use the dropdowns to select a totem for each element (Air, Earth, Fire, Water).
- The macro updates automatically when you select a totem; you can also click "Apply Macro Now" to force an update.
The addon creates/updates a macro named "TMM-MACRO" containing a castsequence of the selected totems.

Notes:
- Macro creation is blocked during combat; updates are queued until you leave combat.
- You can enter custom spell names if a suggestion isn't present.
